# Dragonfly Gate B — PowerShell 7 provider-runtime compatibility

Scope: source-only, uninstalled, synthetic/runtime-capability preflight. Owner: infrastructure-tools #139; no change to the accepted V2 immutable publisher, V1 release, #10 dispatcher, GitHub workflow_dispatch or privileged broker catalog.

The accepted pinned V2 production entrypoint `ci-dispatch/Invoke-DragonflyCanaryProduction.ps1` uses `System.Diagnostics.ProcessStartInfo.ArgumentList` for the narrowly scoped JIT config POST and runner DELETE. This .NET API is **absent** in Windows PowerShell 5.1 and available on the verified LDW01 PowerShell 7.6.9 runtime. The corrected V2 *publisher* synthetic tests under PowerShell 5.1 and 7 do **not** mean its separate *provider entrypoint* can execute under Windows PowerShell 5.1.

`DragonflyGateBPowerShellRuntime.psm1` exports only `Assert-LdwDragonflyProviderShell`. It checks **Windows + Core PowerShell >=7 + ProcessStartInfo.ArgumentList** in memory, performs **no process launch, network call, file mutation, GitHub API call, credential discovery, or host configuration**, and emits only `DRAGONFLY_GATEB_PWSH7_RUNTIME=PASS_LOCAL_ONLY` on local compatibility; all other runtime cases throw `DRAGONFLY_GATEB_PWSH7_REQUIRED`. A PASS is **not trusted process provenance, JIT admission, owner consent, or a claim of installed/verified V2**.

A future independently reviewed **fixed, protected, closed one-shot operator** must enforce this runtime requirement **inside the exact session actually invoking the pinned production entrypoint**, with a separately verified trusted/signed PowerShell 7 executable, `-NoProfile -NonInteractive`, safe environment and command resolution, fixed immutable release/payload hashes, live owner permissions, protected V1 readback and all #10, A4, provider, guest and cleanup controls. Do not use ambient PATH, an untrusted caller-selected exe or `powershell.exe` 5.1. This module is a dependency helper, **not** a launcher or security authorization source; it must not be promoted independently into the protected helper.

Synthetic proof: `./ci-dispatch/tests/Test-DragonflyGateBPowerShellRuntime.ps1` exercises eight pure policy cases and the actual current shell, including Windows PS5.1 fail-closed, Windows PS7 positive and Linux/non-Core failure, without importing or invoking the provider entrypoint. Hosted workflow runs it on Ubuntu pwsh, Windows pwsh and Windows PowerShell 5.1. The immutable V2 release pinned at source commit `bc29bedbfe7fe8a545ce3a471e0d575c2921cefe` remains unmodified; no provider writes or runtime install result from these tests.

All live V2 publication and Gate B approvals and gates remain controlled by #139, source PR220's separate clean independent security review, and #52/#186 reviewed promotion implementation. No new subscription/credential, paid cost, scheduler or standing runner. $0 incremental.
